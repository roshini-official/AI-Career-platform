# 🚀 AI Career Platform – CareerInfinity

### Your AI-Powered Career Guidance and Interview Preparation Platform

CareerInfinity is an AI-powered career guidance platform designed to help students and job seekers identify suitable career paths, evaluate their skills, understand skill gaps, and prepare for technical interviews.

The platform combines Artificial Intelligence, Machine Learning, and Natural Language Processing to provide personalized career recommendations and interview preparation support.

---

## ✨ Key Features

- 📄 **Resume Analysis** – Upload and analyze resumes to extract relevant information and skills.
- 🧠 **AI-Based Career Prediction** – Predict suitable career paths based on skills, education, and experience.
- 🎯 **Skill Gap Analysis** – Identify missing technical and professional skills required for target careers.
- 📊 **Career Recommendations** – Display ranked career suggestions based on prediction results.
- 💡 **Resume Improvement** – Provide suggestions to improve resume quality.
- 💻 **Interview Preparation** – Practice technical and career-related interview questions.
- 📚 **Question Categories** – Explore interview questions based on career tracks and difficulty levels.
- 🔐 **User Authentication** – Secure registration and login functionality.

## 🚀 Getting Started

### Prerequisites

- Node.js
- Python
- MongoDB
- Docker Desktop
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/roshini-official/AI-Career-platform.git
```

**2. Navigate to the project directory**

```bash
cd AI-Career-platform
```

**3. Install dependencies**

Install frontend and backend dependencies in their respective directories:

```bash
npm install
```

Install Python dependencies:

```bash
pip install -r requirements.txt
```

**4. Configure environment variables**

Create the required `.env` files and configure database connections, authentication secrets, and service URLs.

**5. Run the application**

If Docker Compose is configured:

```bash
docker compose up --build
```
