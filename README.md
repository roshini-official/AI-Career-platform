## 📌 About the Project

**AI Career Platform** is an intelligent career development solution that combines Artificial Intelligence, Machine Learning, and modern web technologies to simplify career planning.

The platform helps users evaluate their existing skills, identify skill gaps, explore career opportunities, analyze resumes, and improve their placement readiness through personalized recommendations.

## ✨ Key Features

| Feature | Description |
|---|---|
| 🤖 AI Career Guidance | Personalized career recommendations based on user profiles |
| 📄 Resume Analysis | Analyzes uploaded resumes and extracts relevant information |
| 🎯 Skill Gap Analysis | Identifies missing skills and areas for improvement |
| 💼 Career Explorer | Helps users discover suitable career opportunities |
| 📝 Skill Assessments | Evaluates technical knowledge through assessments |
| 📚 Learning Paths | Provides structured learning recommendations |
| 🎤 Mock Interviews | Supports interview preparation and practice |
| 🏢 Placement Opportunities | Provides job and placement-related information |
| 📊 User Dashboard | Displays career insights and user progress |

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/roshini-official/AI-Career-platform.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd AI-Career-platform
```

### 3️⃣ Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### 4️⃣ Backend Setup

Open a new terminal:

```bash
cd backend
npm install
```

Configure the required environment variables and use the start command defined in `backend/package.json`.

### 5️⃣ AI Service Setup

Open another terminal:

```bash
cd ai-service
pip install -r requirements.txt
```

Run the service using its configured application entry point.
